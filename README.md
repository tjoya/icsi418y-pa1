## Description
My task list is a easy to use task management web page. It allows users to add tasks, choose a priority for their task (High, Medium, Low) mark tasks as complete/incomplete or delete tasks.

## Instruction to Run
1. Download or clone the repository.
2. Open index.html in a web browser.
